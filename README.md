# 设备资产与维保台账

用于本地设备资产管理的命令行项目：登记设备、记录存放位置的历次变更、登记维保计划并提供到期提醒查询。

需要 Python 3.12，仅使用标准库（含 `sqlite3`），无第三方依赖。在仓库根目录运行：

```bash
python3 -m asset_ledger --help
python3 -m asset_ledger --version
python3 -m unittest discover -s tests -v
```

## 数据文件位置

业务数据保存在本地 sqlite3 文件中，查找顺序：

1. 命令行 `--db` 选项，例如 `--db /path/to/ledger.db`（可放在子命令前或后）；
2. 环境变量 `ASSET_LEDGER_DB` 指定的路径；
3. 以上都未指定时，使用**当前工作目录**下的 `.asset_ledger.db`。

数据文件首次执行业务子命令时自动创建；多次运行之间数据持久保存。

## 子命令

### 登记资产：`register`

```bash
python3 -m asset_ledger register \
  --id A001 \
  --name 笔记本电脑 \
  --category IT设备 \
  --purchase-date 2026-01-15 \
  --cost 9999.50 \
  --location 北京办公室
```

- `--id` 资产编号，全局唯一，是后续所有操作的主键；
- `--name` 名称、`--category` 类别、`--location` 初始存放位置（均不能为空）；
- `--purchase-date` 购置日期，格式必须为 `YYYY-MM-DD`；
- `--cost` 购置金额，以元计的非负十进制数（如 `0`、`1299.00`、`0.0001`；不接受负数、科学计数法）。

登记成功后资产处于“在用”状态，输出资产编号、状态与初始存放位置，同时写入第一条位置记录（登记时的初始位置）。

资产编号重复、任一必填项缺失、日期格式非法或金额非法时，命令以非零状态退出并在 stderr 说明原因，**不写入任何数据**，也不会覆盖先前登记的资产。

### 变更存放位置：`move`

```bash
python3 -m asset_ledger move --id A001 --location 上海分部 --date 2026-03-01
```

- `--id` 指定已登记的资产编号；
- `--location` 新的存放位置；
- `--date` 变更日期，格式 `YYYY-MM-DD`。

成功后输出该设备的当前存放位置，并向位置历史**追加**一条记录，历史只增不改。初始位置始终是第一条记录；同一日期允许多次变更，按录入顺序排列。

变更日期不得早于该设备的购置日期，也不得早于最后一条位置记录的日期；对未登记的编号执行变更同样以非零状态退出并在 stderr 提示，不会顺带创建资产或写入记录。

### 登记报废：`scrap`

```bash
python3 -m asset_ledger scrap --id A001 --date 2026-09-01 --reason 设备老化无法维修
# 可选幂等键，便于失败重试：
python3 -m asset_ledger scrap --id A001 --date 2026-09-01 --reason 设备老化无法维修 \
  --request-id REQ-20260901-001
```

- `--id` 必须是已登记且状态为“在用”的资产编号；
- `--date` 报废日期，格式 `YYYY-MM-DD`，且不得早于该资产最后一条位置记录的日期；
- `--reason` 报废原因（不能为空）；
- `--request-id` 可选的请求编号（非空字符串），作为重复提交的幂等键。

报废成功后资产状态变为字面值“已报废”，输出资产编号、状态与报废日期，并向报废历史**追加**一条记录（只增不改）。未登记编号、已报废资产重复报废、日期格式非法或报废原因为空，均以非零状态退出并在 stderr 说明原因，不写入任何数据、不改动既有状态与历史。

带请求编号时：同一数据文件内，若该请求编号已成功报废过同一资产，且资产编号、报废日期、报废原因与首次**完全一致**，重复提交仍返回成功并输出相同结果，但不会追加第二条记录；任一内容不同则以非零状态退出且不写入。不带请求编号按普通登记处理，重复报废同一资产仍然失败。

已报废资产仍可用 `show` 查询（状态输出“已报废”），但不能再执行 `move` 或 `plan-register`：这两类操作对已报废资产以非零状态退出且不产生任何记录。


### 查询资产：`show`

```bash
python3 -m asset_ledger show --id A001
```

按资产编号输出资产基本信息（编号、名称、类别、购置日期、购置金额）、当前状态、当前存放位置，以及按时间与录入顺序排列的完整位置变更历史，供维保与盘点核对。查询不存在的编号以非零状态退出并在 stderr 提示。

### 登记维保计划：`plan-register`

```bash
python3 -m asset_ledger plan-register \
  --plan-id P001 \
  --asset-id A001 \
  --type 常规保养 \
  --first-due-date 2026-06-30 \
  --period-days 90
```

- `--plan-id` 计划编号，全局唯一，是维保记录的业务主键；
- `--asset-id` 必须是已登记的资产编号（不会顺带创建资产）；
- `--type` 维保类型（不能为空）；
- `--first-due-date` 首次到期日期，格式必须为 `YYYY-MM-DD` 且为有效日历日期；
- `--period-days` 周期天数，必须是正整数（如 `90`；不接受 `0`、`-3`、`1.5`、`abc`）。

登记成功后输出计划编号、资产编号与首次到期日期。同一资产可先后登记多个计划，历史只增不改（不提供修改或删除）。

计划编号重复、资产未登记、日期非法或周期非法时，命令以非零状态退出并在 stderr 说明原因，**不写入任何数据**，也不会覆盖或改动先前登记的那条计划。

### 按资产查询维保计划：`plan-list`

```bash
python3 -m asset_ledger plan-list --asset-id A001
```

列出该资产的全部维保计划，每条含计划编号、维保类型、首次到期日期、周期天数，按首次到期日期升序、同一日期按录入顺序排列。资产未登记时以非零状态退出并在 stderr 提示。

### 到期待办清单：`dues`

```bash
python3 -m asset_ledger dues --cutoff-date 2026-09-30
```

列出所有**下一次到期日期**早于或等于截止日期（含恰好相等）的计划，每条输出计划编号、资产编号、维保类型、下一次到期日期以及该资产当前存放位置，按到期日期升序、同一日期按录入顺序排列。截止日期格式必须为 `YYYY-MM-DD`。

下一次到期日期由首次到期日期与周期天数推算：取满足“首次到期日期 + k × 周期天数 ≤ 截止日期”（k 为非负整数）的最近一次日期；首次到期已晚于截止日的计划不进入清单——已登记未到期属于正常情况，不是错误。

## 数据与一致性说明

- 日期与金额均按输入原样保存、原样输出：金额不做四舍五入，日期不做时区换算；
- 每次登记或变更在单个数据库事务内完成，要么整体成功，要么整体不生效；
- 命令失败后修正输入重新执行，结果与从未失败过完全一致。
