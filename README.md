# 设备资产与维保台账

用于本地设备资产管理的命令行项目：登记设备、记录存放位置的历次变更并提供查询。

需要 Python 3.12，仅使用标准库（含 `sqlite3`），无第三方依赖。在仓库根目录运行：

```bash
python3 -m asset_ledger --help
python3 -m asset_ledger --version
python3 -m unittest discover -s tests -v
```

## 数据文件位置

业务数据保存在本地 sqlite3 文件中，查找顺序：

1. 命令行 `--db` 选项，例如 `--db /path/to/ledger.db`（可放在子命令前或后）；
2. 环境变量 `ASSET_LEDGER_DB` 指定的路径；
3. 以上都未指定时，使用**当前工作目录**下的 `.asset_ledger.db`。

数据文件首次执行业务子命令时自动创建；多次运行之间数据持久保存。

## 子命令

### 登记资产：`register`

```bash
python3 -m asset_ledger register \
  --id A001 \
  --name 笔记本电脑 \
  --category IT设备 \
  --purchase-date 2026-01-15 \
  --cost 9999.50 \
  --location 北京办公室
```

- `--id` 资产编号，全局唯一，是后续所有操作的主键；
- `--name` 名称、`--category` 类别、`--location` 初始存放位置（均不能为空）；
- `--purchase-date` 购置日期，格式必须为 `YYYY-MM-DD`；
- `--cost` 购置金额，以元计的非负十进制数（如 `0`、`1299.00`、`0.0001`；不接受负数、科学计数法）。

登记成功后资产处于“在用”状态，输出资产编号、状态与初始存放位置，同时写入第一条位置记录（登记时的初始位置）。

资产编号重复、任一必填项缺失、日期格式非法或金额非法时，命令以非零状态退出并在 stderr 说明原因，**不写入任何数据**，也不会覆盖先前登记的资产。

### 变更存放位置：`move`

```bash
python3 -m asset_ledger move --id A001 --location 上海分部 --date 2026-03-01
```

- `--id` 指定已登记的资产编号；
- `--location` 新的存放位置；
- `--date` 变更日期，格式 `YYYY-MM-DD`。

成功后输出该设备的当前存放位置，并向位置历史**追加**一条记录，历史只增不改。初始位置始终是第一条记录；同一日期允许多次变更，按录入顺序排列。

变更日期不得早于该设备的购置日期，也不得早于最后一条位置记录的日期；对未登记的编号执行变更同样以非零状态退出并在 stderr 提示，不会顺带创建资产或写入记录。

### 查询资产：`show`

```bash
python3 -m asset_ledger show --id A001
```

按资产编号输出资产基本信息（编号、名称、类别、购置日期、购置金额）、当前状态、当前存放位置，以及按时间与录入顺序排列的完整位置变更历史，供维保与盘点核对。查询不存在的编号以非零状态退出并在 stderr 提示。

## 数据与一致性说明

- 日期与金额均按输入原样保存、原样输出：金额不做四舍五入，日期不做时区换算；
- 每次登记或变更在单个数据库事务内完成，要么整体成功，要么整体不生效；
- 命令失败后修正输入重新执行，结果与从未失败过完全一致。
